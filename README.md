# C Unblocked Games

A modern, gallery-style unblocked games website with proxy support and stealth features.

## 🎮 Features

### Games
- **Falling Cubes** - Stack and match falling cubes
- **Sudoku** - Classic number puzzle game
- **Bubble Man Runner** - Run and dodge obstacles

### 🔒 Stealth Mode (about:blank)
Every game and proxy can be opened in **about:blank** mode to hide from monitoring tools like GoGuardian:
- Click the **"🔒 Stealth"** button on any game card
- Click the **"🔒 Open in Stealth"** button on proxy pages
- Opens in a blank page that won't show up in browser history or monitoring

## 🚀 Usage
1. Open `index.html` in your browser
2. Browse games from the gallery
3. Use "Play" for normal mode or "🔒 Stealth" for about:blank mode
4. Click proxy buttons to access different proxy sites
5. Configure tab cloaking in Settings (⚙️)
